# 📸 Скриншоты для README

Сюда идут скрины экранов приложения. Ссылки в главном `README.md` уже настроены и подтянут файлы автоматически.

## Обязательные файлы (имена — точно как ниже)

| Файл | Что снять | Экран |
|------|-----------|-------|
| `splash.png` | Логотип DARK DEED | Первое что видно при открытии |
| `main.png` | Меню + промо + вкладки | Тап на кнопку меню в TG |
| `product.png` | Раф «Тёмный шоколад» с опциями | Тап на большую hero-карточку |
| `cart.png` | Корзина с 2-3 позициями | Иконка корзины сверху |
| `checkout.png` | Оформление заказа | «Оформить заказ» из корзины |

Опционально добавь:
- `profile.png` — экран профиля с аватаром
- `orders.png` — история заказов
- `status.png` — статус заказа в процессе готовки

## Требования к файлам

- **Формат:** PNG (можно JPG, но PNG чётче)
- **Размер:** ≤ 1 MB каждый (GitHub тормозит на больших)
- **Ширина:** 400-800 px достаточно (iPhone-скрины ужмутся сами при вставке)
- **Ориентация:** портретная (390×844 идеально)

## Как сжать скрин если он >1 MB

Открой https://squoosh.app → перетащи фото → выбери **MozJPEG** или **OxiPNG** → скачай. Уменьшит в 3-5 раз без потери качества.
